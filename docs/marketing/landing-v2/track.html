    Tracking FAQ

    Why do I need the last 3 mobile digits?

    This extra step keeps public tracking useful without exposing private shipment details to anyone who only has a reference number.

    Will my request change the shipment immediately?

    No. Reschedule and location updates are routed to the operations team for review before any shipment change is applied.

    What if I cannot verify the shipment?

    Double-check the reference and the last 3 digits of the receiver mobile number. If it still fails, contact the delivery team directly.
